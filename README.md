# AccountMining

A web application built with React and Vite for mining HCL account data.

## Overview

This project provides a modern React front‑end powered by Vite, featuring hot module replacement, ESLint configuration, and a clean UI for interacting with account mining data.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- Responsive React components
- Vite development server with fast reload
- ESLint rules for code quality
